# CLAUDE.md — Learning Archive

This folder is my personal learning archive. It is an index of my thinking: the questions I asked, the artifacts I chose to develop, and links back to the original sources.

## Structure
- `INDEX.md` lists every session, newest first: date, topic, tags, one-line takeaway.
- `sessions/YYYY-MM-DD_topic-slug/` holds one folder per learning session.
  - `SESSION.md` contains the notebook link, tags, file list and a summary of what I learned and how far I got.
  - `questions.md` contains my questions in the order I asked them. Never reorder them.
  - `artifacts/` holds the pages, tables and decks I chose to keep.
- `inbox/` holds material that isn't filed yet.

## Rules
- When filing, **never guess**. If the session, date or topic is unclear, leave the item in `inbox/` and tell me.
- Always update `INDEX.md` after creating or changing a session.
- Don't open artifacts to answer questions unless I ask. `SESSION.md` should be enough.
- Tags are lowercase and hyphenated (`harness-engineering`), and existing tags are reused before new ones are created.
- Never delete anything. Archive superseded material into `artifacts/old/`.

## Answering questions
- "What did I learn about X?" → find matching sessions via INDEX.md tags, then report date, tags, the progression of questions, notebook link and artifact list.
- "What did I learn in <month>?" → filter INDEX.md by date.
- "All my questions about Y" → search every `questions.md` and group the matches by session.
