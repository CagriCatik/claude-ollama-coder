# AI Agent Engineering

## Why I studied this
To understand how two newer ideas (harness engineering and loop engineering) relate to prompt and context engineering, so I can design the setup for an autonomous test agent.

## What I learned
- Prompt and context engineering shape what a **single model call** sees.
- Harness engineering shapes the **system around the model**: tools, error channels, agents.
- Loop engineering shapes **how runs repeat and improve**: evaluate → feed back → run again.
- The layers become hard to follow in text once tools and feedback appear, so an interactive layer view helped.

## How far I got
Understood the four layers conceptually. Next: map my own test agent onto the harness and loop layers.
