# Lab 01 — First Project

**Time:** 15 min · **Module:** [00 Getting Started](../00-getting-started/README.md)

## Steps
1. Create an empty folder `log-summarizer`.
2. Desktop app → **Code** tab → open the folder (or `cd log-summarizer && claude`).
3. Leave model on default, effort on **medium**, mode on **auto**.
4. Run:
   ```text
   Initialize a git repository here and create a sample file logs/sample.log
   with 50 realistic lines of application logs (INFO/WARN/ERROR, timestamps).
   ```
5. Open the **Files** panel and the **Changed files** panel and look at what happened.
6. Try a follow-up that refines instead of re-prompting:
   ```text
   Add 5 more ERROR lines from a "database" component.
   ```

## ✅ Done when
- [ ] The folder shows up as a project in the sidebar
- [ ] `logs/sample.log` exists and git is initialized
- [ ] You saw at least one diff in the Changed-files view
