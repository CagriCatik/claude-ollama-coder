## The six-level ladder (from the beginner video)

```mermaid
flowchart BT
    L1["1 · Talk<br/>three-part prompts, reply & refine, models"] --> L2
    L2["2 · Hand it your stuff<br/>files, images, web search, research"] --> L3
    L3["3 · Make real things<br/>files & artifacts"] --> L4
    L4["4 · Make it remember you<br/>projects, instructions, memory"] --> L5
    L5["5 · Connect your world<br/>connectors, skills"] --> L6
    L6["6 · Let it work without you<br/>file automation, schedules, Claude Code"]
```

The same skill runs through every level: **give context, give a task, refine the result.**
